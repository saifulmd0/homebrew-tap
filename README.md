# Homebrew tap

Homebrew casks by [Saiful Islam](https://github.com/saifulmd0).

## Bangla Voice Clock

A free menu bar clock that announces the time aloud in Bangla
([source and details](https://github.com/saifulmd0/bangla-voice-clock)).

```sh
brew install --cask saifulmd0/tap/bangla-voice-clock
```

Update it with `brew upgrade --cask bangla-voice-clock`, and remove it with
`brew uninstall --cask bangla-voice-clock` (add `--zap` to delete its settings too).

The cask is generated from
[`macos/homebrew/`](https://github.com/saifulmd0/bangla-voice-clock/tree/main/macos/homebrew)
in the app's repository and updated automatically with each release; change it there.
